# AI Agent Instructions

## Project Overview

Agent Ops Kit is a task-centered toolkit for making software repositories easier and safer for AI agents to inspect, improve, and operate.

The first version is intentionally narrow: run a read-only repo readiness sweep, persist the result locally, and write a Markdown report.

## Technology Choices

- Use Python 3.13.
- Use `uv` for dependency management.
- Use FastAPI for the service boundary.
- Use Typer for CLI commands.
- Use SQLModel for persisted models.
- Use Alembic for every schema change.
- Use SQLite for local development and per-repo readiness state.

## Environment Setup

- Use `uv` for dependency management and `uv run` for executing Python commands not covered by the Makefile.
- The project includes a local development environment through `make` commands.
- Always prefer `make` commands when available.
- Run `make install` before running checks in a fresh clone, new worktree, or recreated virtual environment.

## Common Commands

```bash
make install
make format
make lint
make test
make typecheck
make check
make sweep REPO=/path/to/repo
make dev
```

## Database Rules

- All database schema changes must be managed through Alembic migrations.
- SQLModel models are the source of truth.
- Update models first, then generate migrations with `uv run alembic revision --autogenerate -m "<message>"`.
- Never manually modify the database schema outside of migrations.
- Review autogenerated migrations before committing them.

## Development Workflow

1. Bootstrap the environment with `make install`.
2. Make the smallest useful change.
3. Run focused validation for the touched surface.
4. Run `make check` before handoff when Python behavior changed.
5. Update `README.md` when installation, commands, project structure, workflow, or user-facing behavior changes.

## Safety Boundaries

- Read source repositories by default.
- Do not edit, commit, push, open PRs, delete files, or mutate external systems unless a user explicitly asks.
- Store local sweep output under `.agent-readiness/` in the inspected repo.
- Keep secret values out of reports, logs, fixtures, and tests.

## Coding Guidance

- Keep workflow logic reusable from both the CLI and FastAPI.
- Prefer deterministic checks before adding LLM judgment.
- Keep tasks small, explicit, and evidence-backed.
- Tests should verify behavior at command, API, database, and report boundaries.
